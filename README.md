## What I build

I work at the intersection of **data engineering**, **AI systems**, and **DevOps** — designing infrastructure end-to-end, from raw ingestion to production deployment.

My focus areas:
- 🔗 **Data contracts & schema integrity** — catching drift before it breaks downstream systems
- 🤖 **Agentic pipelines** — multi-agent architectures with reproducible, auditable decisions
- 📄 **Intelligent document extraction** — turning unstructured enterprise documents into structured, provenance-aware data
- 📊 **End-to-end data pipelines** — from raw ingestion to analytics-ready warehouses
- ⚙️ **DevOps & infrastructure** — containerised workloads, CI/CD pipelines, and reliable deployments
